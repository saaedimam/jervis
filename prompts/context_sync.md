# CONTEXT SYNCHRONIZATION (MANDATORY)

Before completing ANY task:
1. Run all required validation (tests, lint, architecture checks).
2. Update SESSION_CONTEXT.md with:
   - Current phase
   - Work completed
   - Files modified
   - Decisions
   - Validation results
   - Open issues
   - Next task
3. Review SESSION_CONTEXT.md.
4. Merge permanent information into:
   - PROJECT_CONTEXT.md
   - ADR_INDEX.md (if applicable)
   - MILESTONES.md (if applicable)
   - API_FREEZE.md (if applicable)
   - ARCHITECTURE_HISTORY.md (if applicable)
5. Archive SESSION_CONTEXT.md into:
   context/sessions/YYYY-MM-DD-session-XX.md
6. Create a fresh SESSION_CONTEXT.md for the next working session.
7. Verify all context documents are consistent.

A task is NOT complete until this workflow has finished.
